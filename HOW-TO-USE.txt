STEPHY PAK PORTFOLIO — HOW TO USE

1. Open in VS Code:  File → Open Folder → choose this "stephy-pak-portfolio" folder.
2. Preview it:       right-click index.html → "Open with Live Server".
                     (Install the "Live Server" extension first if you don't have it.)
3. Save (Cmd+S) and the browser updates by itself.

TO ADD YOUR OWN STUFF
  - Anything in [square brackets] is a placeholder — replace it.
  - Images: drop them in assets/projects/, then change
    src="assets/projects/placeholder.svg"  →  src="assets/projects/your-image.jpg"
  - Social links: search for  href="#"  in each page and paste your real links.
